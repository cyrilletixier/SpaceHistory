Les {{ stats.launches | int_fr }} tentatives de lancement orbital recensées par le GCAT depuis le 4 octobre 1957. Une ligne = un lancement : les objets d'un même tir sont agrégés par Launch_Tag au moment du build, et le nombre d'objets reste affiché séparément.

{{ stats.launches | int_fr }} lancements

Statut dérivé du code Launch_Code du GCAT (OS = succès orbital, OF = échec orbital, DS = départ vers l'espace lointain) ; l'échec prime sur les autres pièces d'un même tir, et le code brut est affiché à côté. {% if stats.unknown %} Les {{ stats.unknown | int_fr }} lancements portant un autre code (NS, NF, XS) restent en « inconnu » : ce ne sont pas des issues orbitales, et les ranger d'autorité dans une colonne fausserait les taux. {% endif %} Sites, agences et pays sont nommés d'après sites.tsv et orgs.tsv, avec le code GCAT en infobulle. {{ source_rows | int_fr }} lignes brutes dans le fichier source, agrégées en {{ stats.launches | int_fr }} lancements.

Charges utiles : le compteur renvoie vers la page des charges utiles filtrée sur le vol (charges-utiles.html?vol=…). Masse en orbite : somme du champ Mass de satcat.tsv pour les charges utiles (= Type commençant par P) effectivement cataloguées en orbite ; le 0 de remplissage du GCAT est tenu pour inconnu, et un vol dont aucune masse n'est connue affiche « — » plutôt qu'un zéro trompeur. Une charge perdue lors d'un échec n'entre pas dans la somme : elle figure dans ftocat.tsv, donc sur la page des charges utiles seulement. Destination : famille d'orbite déduite de OpOrbit (LLEO/I → LEO) ; un vol à destination mixte affiche plusieurs familles, et un code d'orbite inconnu reste affiché tel quel.
